# lifecom-role-frontend

前端工程師的 AI Agent 支援腳本。負責使用者介面開發、UX 實作，向技術經理回報。

---

## 職務基本資訊

| 欄位 | 內容 |
|------|------|
| 職稱 | 前端工程師 |
| 層級 | 執行層（技術團隊） |
| 直屬主管 | 技術經理（TechLead） |
| 技術領域 | UI/UX 實作、前端框架、介面效能 |

---

## 核心職責

| 職責 | 比重 |
|------|------|
| 使用者介面開發與實作 | 45% |
| 前後端 API 串接 | 25% |
| UX 改善與使用性優化 | 15% |
| Bug 修復（前端） | 10% |
| 設計稿轉換（Design to Code） | 5% |

---

## KPI 指標

- **Sprint 任務完成率**：≥ 80%
- **前端頁面載入時間**：LCP < 2.5 秒
- **介面 Bug 修復時間**：P1 < 4 小時，P2 < 24 小時
- **設計還原度**：≥ 90%（與設計稿對比）
- **Code Review 通過率（一次）**：≥ 70%

---

## 日常工作項目

### 每日
- 確認 IT 日報（Slack C02E37Q1CUD）
- 推進當前 Sprint 任務
- 確認設計稿是否有更新

### 每週
- Sprint Review / Planning 參與
- Code Review 參與
- 與設計統籌對齊視覺規格

### 每月
- 前端效能評估報告
- 技術債盤點

---

## 需要的報表/數據

| 報表 | 頻率 | 接收方式 |
|------|------|---------|
| **IT 日報** | 每日 | Slack C02E37Q1CUD |
| **每小時系統快報** | 每小時 | Slack #general |
| Bug 工單清單（前端） | 即時 | ADO 系統 |

---

## AI Agent 支援方式

- 前端 P1/P2 Bug 即時警示
- 設計稿更新通知（設計統籌發布新版本時）
- Sprint 任務進度提醒
- 介面效能指標週報摘要
- Code Review checklist 輔助
