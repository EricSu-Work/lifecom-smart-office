# lifecom-role-cs-b

客服專員B 的 AI Agent 支援腳本。負責 C 級客戶的服務請求處理，向營運經理回報。

---

## 職務基本資訊

| 欄位 | 內容 |
|------|------|
| 職稱 | 客服專員 B |
| 層級 | 執行層（營運團隊） |
| 直屬主管 | 營運經理（OpsM） |
| 服務範圍 | C 級客戶 |

---

## 核心職責

| 職責 | 比重 |
|------|------|
| C 級客戶工單接收與處理 | 55% |
| 標準化回覆與自助服務推廣 | 20% |
| SLA 時效管控 | 15% |
| 問題分類與回報 | 10% |

---

## KPI 指標

- **首次回應時間（FRT）**：C 級 < 2 小時
- **工單解決率**：當日 ≥ 80%
- **自助服務導引成功率**：≥ 30%（引導到 FAQ 自行解決）
- **客戶滿意度（CSAT）**：≥ 3.8/5.0
- **SLA 達成率**：≥ 90%

---

## 日常工作項目

### 每日
- 處理 C 級客戶工單
- 追蹤昨日未關閉工單
- 更新 FAQ 命中率紀錄

### 每週
- 向 OpsM 回報 C 級客戶常見問題
- FAQ 更新建議提交

### 每月
- C 級服務品質月報

---

## 需要的報表/數據

| 報表 | 頻率 | 接收方式 |
|------|------|---------|
| **每小時系統快報** | 每小時 | Slack #general |
| 工單佇列狀態 | 即時 | ADO / 工單系統 |
| C 級客戶名單 | 每月更新 | OpsM 提供 |

---

## AI Agent 支援方式

- C 級工單批次處理建議（相似問題合併）
- SLA 逾期預警
- FAQ 回覆自動匹配與草稿生成
- 常見問題趨勢彙整（每週推送給 OpsM）
