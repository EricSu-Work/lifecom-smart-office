# skill-changelog — 發布說明自動生成

來源：https://github.com/ComposioHQ/awesome-claude-skills（Changelog Generator）

## 功能
從 git commits 或 Slack 上板記錄，自動產生用戶友善的 Release Notes / Changelog。

## 適用場景
- 每次上板後的客戶更版通知 Email
- 技術團隊 Release Notes
- 內部版本紀錄整理

## 使用方式
提供 commit log 或上板記錄，說明目標受眾（客戶/技術），Agent 輸出對應格式的說明文件。
