# skill-mcp-builder — MCP Server 建立

來源：https://github.com/ComposioHQ/awesome-claude-skills（MCP Builder）

## 功能
建立高品質 MCP（Model Context Protocol）Server，整合外部 API 與 LLM 工具。

## 適用場景
- 整合第三方 API（Momo、LineGift、倉庫系統）
- 建立新的 AI Agent 工具
- 擴充 OpenClaw 能力

## 使用方式
說明要整合的 API 或服務，Agent 產生 Python 或 TypeScript 的 MCP Server 架構。
