## 待建模組規劃

### 🔴 P0 — 核心財務（最影響決策）

#### F-01 應收帳款追蹤（AR Dashboard）
- **資料源**：立富康 115/114 xlsx
- **內容**：
  - 各客戶未收款金額 + 帳齡分析（30/60/90/120天）
  - 逾期客戶清單 + 負責業務
  - 本月應收 vs 實收差異
  - 下月預期收款預測
- **告警**：逾期 >30天 → 通知 CEO + OP主管

#### F-02 現金流預測（Cash Flow）
- **資料源**：應收 xlsx + 應付（手動輸入或 Google Sheets）
- **內容**：
  - 未來 30/60/90 天現金流預測
  - 關鍵付款日提醒
  - 流動資金安全水位警示

#### F-03 P&L 月報
- **資料源**：應收 + 薪資 + 費用（需接入會計系統或 Sheets）
- **內容**：
  - 收入 / 成本 / 毛利 / 淨利
  - 各業務線拆分（OMS/WMS/TMS/通路）
  - YoY / MoM 趨勢

---

### 🟠 P1 — 客戶管理（直接影響留存率）

#### C-01 客戶健康度總表（Customer Health）
- **資料源**：ADO Bug (by 客戶) + 系統告警 + 部署記錄
- **內容**：
  - 每客戶綜合健康燈號（🔴🟡🟢）
  - 評分維度：Bug數/SLA達成/未結工單帳齡/近期部署
  - CEO 每週一次全客戶健康掃描

#### C-02 合約到期追蹤
- **資料源**：Google Sheets（需建立合約清單）
- **內容**：
  - 各客戶合約到期日
  - 提前 90/60/30 天提醒 CEO + 業務
  - 授權到期（Shopee/EC平台 API）提醒

#### C-03 NPS / 客戶滿意度
- **資料源**：Google Form 或手動季度調查
- **內容**：NPS 趨勢 / 分客戶滿意度分數

---

### 🟠 P1 — 業務/成長（影響收入擴張）

#### S-01 銷售管道追蹤（Sales Pipeline）
- **資料源**：Google Sheets 報價單 (已有：1nrYYHEBNNnhoRqCfkm_n2eG6QqnRPe0Iai0k57FUrto)
- **內容**：
  - 各機會狀態（初接觸/報價/談判/簽約）
  - 預期簽約金額 + 機率加權
  - 本季目標 vs 現況
  - 逾期未跟進的報價單告警

#### S-02 客戶擴充追蹤（Upsell/Cross-sell）
- **內容**：
  - 現有客戶還未開的模組清單
  - 近期有提需求但未立案的機會

### 🟡 P2 — 工程效能（影響交付品質）

#### E-01 工程 KPI 週報
- **資料源**：ADO
- **內容**：
  - 部署頻率（每週次數）
  - Bug 修復週期（開立→關閉平均天數）
  - 殭屍工單率（>30天未動 / 總工單）
  - 工程師個人負載 vs SLA達成率

#### E-02 技術債看板
- **資料源**：ADO Epic（維運工單帳齡分析）
- **內容**：
  - 帳齡 >90天的維運工單清單
  - 按客戶 / 工程師分組
  - 每月一次技術債報告 → CTO

#### E-03 系統可用性 SLA
- **資料源**：Slack 系統告警頻道 C03TBQ5891V
- **內容**：
  - 各客戶站台本月告警次數 / 時長
  - 99.x% 可用性計算
  - P0/P1 事件事後報告（PIR）

### 🟡 P2 — 人力/組織

#### H-01 工程師負載週報
- **資料源**：ADO（已有部分）
- **內容**：

### 🔵 P3 — 策略/長期

#### M-01 月度 CEO 策略報告
- **整合**：財務 + 客戶健康 + 工程效能 + 銷售管道
- **格式**：PDF 或 Google Docs 月報
- **收件**：董事會 / 投資人

#### M-02 OKR 進度追蹤
- **資料源**：Google Sheets（需建立 OKR 清單）
- **內容**：季度 OKR 進度 + 關鍵風險

## 建議實作順序

```
Phase 1（本月）：
  F-01 應收帳款追蹤 ← 從現有 xlsx 延伸，成本最低
  S-01 銷售管道 ← 報價單 Sheets 已存在
  C-02 合約到期 ← 需建立 Sheets，一次性工程

Phase 2（下月）：
  C-01 客戶健康度總表 ← 整合現有 ADO data
  E-01 工程 KPI 週報 ← 擴充現有 ADO 模塊
  H-01 工程師負載週報 ← 現有資料已夠

Phase 3（Q2）：
  F-02 現金流預測 ← 需接入更多財務資料
  F-03 P&L 月報 ← 需接入薪資/費用
  E-02 技術債看板
  M-01 月度策略報告
```
